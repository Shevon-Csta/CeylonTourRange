Importing into Figma

1. Install the free html.to.design plugin in Figma.  2. Open a screen in Chrome and copy its URL (or use the plugin's browser extension on the open page).  3. In Figma: Plugins → html.to.design → paste the URL/capture the tab. Each screen imports as an editable frame with layers, text styles, and images intact. Repeat per screen; see design/mockups/README.md for details.
